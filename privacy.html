PayParse プライバシーポリシー

本プライバシーポリシーは、アプリケーション「PayParse」（以下、「本アプリ」）におけるデータの取り扱いについて定めたものです。

1. アプリの目的と利用者

本アプリは開発者本人の個人利用のみを目的とした専用ツールであり、一般向けに公開・提供されているものではありません。

2. 取得する情報と利用目的

本アプリは、ユーザー（開発者本人）の同意に基づき、Gmail APIを利用して特定のメール（クレジットカード等の利用明細）を読み取り、支出管理等の解析目的でのみ利用します。

3. データの第三者提供と保存について

取得したメールデータは開発者の管理する環境（ローカルまたは個人サーバー）でのみ処理されます。第三者へ提供、共有、販売されることは一切ありません。

4. Google API サービスの利用について

本アプリが Google API から取得した情報の使用および他のアプリへの転送は、制限付きの要件（Limited Use requirements）を含む Google API Services User Data Policy に厳格に準拠します。

5. お問い合わせ

本アプリは開発者個人専用のツールであるため、外部からの窓口は設けておりません。
